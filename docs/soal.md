Proyek 1: CLI Expense Tracker (pakai file JSON)
Topik yang kepake: syntax basics, list/dict, function, f-string, basic error handling

Bikin script command-line buat nyatet pengeluaran (nama, jumlah, kategori), simpen ke file JSON, bisa nampilin total per kategori.

Ini murni buat mateng-in syntax dasar Python tanpa distraksi topik lain dulu.
